Editor Save v3

Buka file v3.dat dari game, ubah nilainya, lalu simpan. File diproses di perangkatmu dan tidak dikirim ke mana pun.

  1. Salin v3.dat ke tempat aman sebagai cadangan.
  2. Pilih file itu di sini, ubah nilainya, lalu simpan.
  3. Tutup game sepenuhnya, timpa v3.dat lama dengan hasilnya, lalu buka game.
Tutup game dulu sebelum menimpa save. Game bisa menulis ulang file itu saat masih berjalan.
